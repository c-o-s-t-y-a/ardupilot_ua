# AirMode

> Оригінал: [AirMode](https://ardupilot.org/copter/docs/airmode.html)

Це не окремий flight mode (польотний режим), а важлива функція режимів ACRO і STABILIZE. Інше програмне забезпечення для flight controller (польотний контролер) називає його режимом, тож для узгодженості його включено в документацію режимів Copter.

## Що це

Зазвичай у Copter, якщо arm (переведення в робочий стан) налаштовано через stick (ручка керування) rudder, то при зниженні throttle (газ) до холостого в режимі ACRO стабілізація вимикається. Це запобігає рухам від вібрацій на землі на холостому throttle, але не дає стабілізації в польоті під час акробатичних фігур чи швидкого зниження.

Якщо для arm використовується перемикач на RC transmitter (пульт радіокерування) з `RCx_OPTION` **ARM/DISARM with Airmode** (опція 154), стабілізація на холостому throttle лишається повністю активною — це часто називають AIRMODE.

> **Примітка.** Щоб не вмикати AIRMODE, але все ж використовувати перемикач **ARM/DISARM**, призначте перемикачу [допоміжна функція](https://ardupilot.org/copter/docs/common-auxiliary-functions.html) *(ще не перекладено)* «153».

AIRMODE можна також зробити активним без використання перемикача `RCx_OPTION` для arm. Якщо призначити каналу RC `RCx_OPTION` = 84, можна вмикати чи вимикати AIRMODE у режимах ACRO і STABILIZE напряму. Крім того, біт 0 `ACRO_OPTIONS` вмикає AIRMODE у режимі ACRO (лише в ньому) постійно, якщо тільки це не перевизначено згаданим вище перемикачем (якщо він використовується).

> **Примітка.** AIRMODE не діє на традиційних гелікоптерах.

> **Примітка.** Недостатньо просто налаштувати arm на перемикачі `RCx_OPTION` — треба *також* справді використовувати його для arm. Тож якщо перемикач налаштовано, але arm виконується через rudder, «airmode» не буде.
