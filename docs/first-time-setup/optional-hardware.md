# Додаткове обладнання

> Оригінал: [Peripheral Hardware](https://ardupilot.org/copter/docs/common-optional-hardware.html)

У цьому розділі зібрано обладнання, яке може бути (а може й не бути) на вашій frame (рама): далекоміри, кріплення камер, радіомодеми telemetry (телеметрія) тощо. Інформацію про вибір autopilot (автопілот) див. у [Autopilot Hardware Options](https://ardupilot.org/copter/docs/common-autopilots.html) *(ще не перекладено)*. Рекомендації щодо проєктування кабелів, кольорового маркування і прокладання дротів з урахуванням електромагнітної сумісності, особливо для більших апаратів з довгими дротами, — у [Cable Wiring Guidelines](https://ardupilot.org/copter/docs/common-cabling-guide.html) *(ще не перекладено)*.

> **Примітка.** У Mission Planner багато з цих датчиків можна налаштувати на екранах **Initial Setup >> Optional Hardware**.
