# Традиційні гелікоптери

> Оригінал: [Traditional Helicopters](https://ardupilot.org/copter/docs/traditional-helicopters.html)

![trex450](https://ardupilot.org/copter/_images/trex450.jpg)

<!-- terms-ignore: pitch -->
Copter підтримує традиційні гелікоптери з одним несучим гвинтом, з двома гвинтами поздовжньої схеми (tandem), а також квадрокоптери із загальним кроком гвинтів (collective pitch) — з усіма тими ж можливостями, що й у мультикоптерів. Здебільшого налаштування таке саме, як для мультикоптерів, але для інформації, специфічної для гелікоптерів, скористайтеся посиланнями внизу сторінки або в бічній панелі.
