# Діапазон моторів

> Оригінал: [Setting Motor Range](https://ardupilot.org/copter/docs/set-motor-range.html)

Більшість ESC (електронний регулятор обертів) мають deadzone (мертва зона) внизу діапазону. Ця сторінка пояснює, як виміряти її розмір, а потім правильно задати оберти в стані armed (у робочому стані) і мінімальний throttle (газ).

Це необов'язково, але досвідчені користувачі можуть піти далі й виміряти та налаштувати [криву тяги моторів](https://ardupilot.org/copter/docs/motor-thrust-scaling.html) *(ще не перекладено)*.

> **Примітка.** Перед налаштуванням діапазону моторів виконайте [калібрування ESC](esc-calibration.md).

## Вимірювання deadzone

- Зніміть пропелери з апарата.
- Підключіть LiPo-батарею.
- Підключіть autopilot (автопілот) до Mission Planner USB-кабелем або через telemetry (телеметрія).
- Відкрийте в Mission Planner сторінку **Initial Setup → Optional Hardware → Motor Test**.

    ![MissionPlanner_MotorTest](https://ardupilot.org/copter/_images/MissionPlanner_MotorTest.png)

- Збільшуйте значення в полі «Throttle %» і натискайте кожну з кнопок «Test motor», щоб визначити, скільки відсотків потрібно кожному мотору, щоб почати обертатися. Якщо всі ESC одного виробника, deadzone у них, найімовірніше, схожа, але різниця в 1–2 % для одного-двох — звичайна річ. Візьміть найбільший відсоток серед усіх моторів — він знадобиться нижче.

## Оберти в стані armed і мінімальний throttle

За замовчуванням, коли апарат armed, але не летить, мотори обертаються трохи повільніше за звичайне. Цю швидкість задає параметр `MOT_SPIN_ARM`. Коли апарат уже летить, треба гарантувати, що на мотори ніколи не піде значення, за якого вони зупиняться; цю нижню межу задає параметр `MOT_SPIN_MIN`.

- Встановіть `MOT_SPIN_ARM` у **(відсоток, знайдений вище, + 2 %) / 100**. Наприклад, якщо deadzone ESC становить 7 %, задайте `MOT_SPIN_ARM` = 0.09 (тобто (7 + 2) / 100).
- Встановіть `MOT_SPIN_MIN` принаймні на 0.03 більше за `MOT_SPIN_ARM`. Наприклад, якщо `MOT_SPIN_ARM` = 0.09, задайте `MOT_SPIN_MIN` = 0.12.

> **Примітка.** `MOT_SPIN_MIN` можна задати й вищим за рекомендоване, щоб врахувати просідання напруги батареї. Але занадто високе значення скорочує нижню частину діапазону моторів, а отже й керованість — це може бути важливо, особливо на потужних коптерах з низьким throttle зависання.

> **Примітка.** Параметр `MOT_SPIN_MAX` враховує самий верх діапазону ESC/мотора, який зазвичай уже не дає додаткової тяги. За замовчуванням — 0.95 (тобто верхні 5 % діапазону додаткової тяги не дають).

> **Примітка.** Якщо використовується telemetry обертів з ESC, параметр `TKOFF_RPM_MIN` можна задати трохи нижче за `MOT_SPIN_ARM`, щоб запобігти спробам зльоту — і перекиданням на зльоті, — якщо один чи кілька моторів не обертаються.

## Час у стані холостого ходу

За потреби параметром `MOT_IDLE_SEC` можна додати затримку між досягненням холостого ходу моторів і моментом, коли на ESC можна подати більший throttle (за замовчуванням 0 секунд).
