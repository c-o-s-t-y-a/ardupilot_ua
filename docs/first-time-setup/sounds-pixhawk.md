# Звуки (Pixhawk)

> Оригінал: [Sounds (Pixhawk)](https://ardupilot.org/copter/docs/common-sounds-pixhawkpx4.html)

Зумер відтворює мелодії, що позначають різні стани. Натисніть опис нижче, щоб завантажити й послухати відповідну мелодію.

- [Збій EKF (розширений фільтр Калмана) або інерціальної навігації](https://download.ardupilot.org/downloads/wiki/pixhawk_sound_files/EKF_Or_InertialNavFailure.wav)
- [Успішний запуск](https://download.ardupilot.org/downloads/wiki/pixhawk_sound_files/PX4_StartUpOk.wav)
- [Помилка запуску](https://download.ardupilot.org/downloads/wiki/pixhawk_sound_files/FailedToStart.wav)
- [Знайдено нову firmware (прошивка) для плати IO (перезапустіть із натиснутою кнопкою безпеки, щоб записати)](https://download.ardupilot.org/downloads/wiki/pixhawk_sound_files/PX4_ReadyToUploadIOBoardFirmware.wav)
- [Нову firmware для плати IO успішно записано](https://download.ardupilot.org/downloads/wiki/pixhawk_sound_files/PX4_CompletedIOBoardFirmwareUpload.wav)
- [Немає SD-карти](https://download.ardupilot.org/downloads/wiki/pixhawk_sound_files/NoSDCard_short.wav)
- [Апарат armed (у робочому стані)](https://download.ardupilot.org/downloads/wiki/pixhawk_sound_files/Armed.wav)
- [Апарат disarmed (не в робочому стані)](https://download.ardupilot.org/downloads/wiki/pixhawk_sound_files/Disarmed.wav)
- [Не вдалося arm (переведення в робочий стан)](https://download.ardupilot.org/downloads/wiki/pixhawk_sound_files/failedToArm.wav)
- [Низький заряд батареї](https://download.ardupilot.org/downloads/wiki/pixhawk_sound_files/LowBattery.wav)
- [Збій GPS](https://download.ardupilot.org/downloads/wiki/pixhawk_sound_files/GPSGlitch.wav)
- [Збій barometer (барометр)](https://download.ardupilot.org/downloads/wiki/pixhawk_sound_files/BaroGlitch.wav)
- [Розкриття парашута](https://download.ardupilot.org/downloads/wiki/pixhawk_sound_files/parachute_release.wav)
