# Налаштування трикоптера

> Оригінал: [Tricopter Configuration](https://ardupilot.org/copter/docs/tricopter.html)

Тут описано спеціальні налаштування, потрібні, щоб трикоптер полетів. Для решти налаштування використовуйте [загальні інструкції для мультикоптера](index.md).

![APM_2_5_MOTORS_TRI](https://ardupilot.org/copter/_images/APM_2_5_MOTORS_TRI.jpg)

Після запису firmware (прошивка) встановіть:

- `FRAME_CLASS` у 7 («Tri»)

Краще розділення параметрів входів і виходів RC також призвело до деяких змін порівняно з попередніми версіями. Ось повний список параметрів, специфічних для трикоптера:

- `MOT_YAW_SV_ANGLE`: максимальний кут нахилу хвостового servo (сервопривід) у градусах. Дає змогу правильно коригувати тягу заднього мотора залежно від кута його нахилу. За замовчуванням 30°. «0» означає, що хвостовий servo може дивитися лише прямо вгору (тоді апарат не зможе летіти), «90» — що хвостовий servo може стати горизонтально.
- `SERVO7_MIN`: найменше значення PWM (широтно-імпульсна модуляція) хвостового servo, до якого ще не настає заклинювання.
- `SERVO7_MAX`: найбільше значення PWM хвостового servo, до якого ще не настає заклинювання.
- `SERVO7_TRIM`: значення PWM хвостового servo, близьке до потрібного, щоб хвіст не обертався.
- `SERVO7_REVERSED`: реверс хвостового servo. 0 = servo рухається в стандартному напрямку, 1 — у зворотному.

Вихідний канал RC для хвостового servo можна змінити зі стандартного (канал 7), встановивши відповідний SERVOX_FUNCTION у 39. Наприклад, у [Pixracer](https://ardupilot.org/copter/docs/common-pixracer-overview.html) *(ще не перекладено)* лише 6 вихідних каналів, тож хвостовий servo можна перенести на вихідний канал 5, встановивши `SERVO5_FUNCTION` у 39. Зверніть увагу: якщо вихідний канал змінено, для нового каналу треба відповідно задати SERVOx_MIN, SERVOx_MAX, SERVOx_TRIM і SERVOx_REVERSED.
