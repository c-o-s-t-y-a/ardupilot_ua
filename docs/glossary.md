# Глосарій

Єдине джерело правди для перекладу термінів. Термін у тексті пишемо англійською;
при **першій** появі на сторінці додаємо в дужках переклад — дослівно з колонки «UA».
Назви параметрів, flight mode-ів, кнопок і меню не є термінами й не перекладаються.

| EN | UA | Коментар |
|---|---|---|
| accelerometer | акселерометр | |
| arm | переведення в робочий стан | дієслово/дія; стан — див. armed |
| armed | у робочому стані | «коли апарат armed» |
| autopilot | автопілот | синонім: flight controller |
| bias | зміщення нуля | |
| compass | компас | |
| disarm | виведення з робочого стану | |
| disarmed | не в робочому стані | |
| ESC | електронний регулятор обертів | |
| failsafe | аварійний захист | |
| flight controller | польотний контролер | синонім: autopilot |
| flight mode | польотний режим | назви режимів (Loiter, RTL…) — без перекладу |
| frame | рама | |
| GCS | наземна станція керування | Ground Control Station |
| level | рівне положення | кнопка **Calibrate Level** — без перекладу |
| log | журнал польоту | множина: log-и, у log-ах |
| pitch | тангаж | |
| roll | крен | |
