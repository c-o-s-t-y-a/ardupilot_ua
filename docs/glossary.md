# Терміни

Технічні терміни в перекладі пишемо **англійською** — так, як їх видно в Mission Planner,
на форумах і в оригінальній документації. При **першій** появі на сторінці поруч у дужках
стоїть український переклад із колонки «UA»; далі на сторінці — лише англійський термін.

Назви параметрів (`FRAME_CLASS`), flight mode-ів (Loiter, RTL), кнопок і меню Mission Planner
(**Calibrate Level**) — це назви в інтерфейсі, а не терміни; їх не перекладаємо.

Ця таблиця — єдине джерело перекладів: текст у дужках на сторінках збігається з колонкою «UA» дослівно.

| EN | UA | Пояснення |
|---|---|---|
| accelerometer | акселерометр | Датчик лінійних прискорень. За напрямком сили тяжіння autopilot визначає нахил апарата, тому accelerometer обов'язково калібрують. |
| arm | переведення в робочий стан | Дія, після якої autopilot дозволяє моторам обертатися і реагує на газ. Перед arm автоматично виконуються pre-arm перевірки. Не плутати з промінням рами (англ. теж *arm*). |
| armed | у робочому стані | Стан апарата після arm: мотори можуть обертатися. Калібрування і більшість налаштувань у цьому стані недоступні. |
| autopilot | автопілот | Плата з процесором і датчиками, на якій працює ArduPilot. Синонім — flight controller. |
| barometer | барометр | Датчик атмосферного тиску; за ним autopilot визначає висоту. Є на всіх autopilot, сумісних з ArduPilot. |
| BEC | стабілізатор живлення | Battery Eliminator Circuit — знижує напругу батареї до 5 В (або іншої) для живлення receiver, servo, шини виходів. Буває вбудованим в ESC. |
| bias | зміщення нуля | Постійна похибка датчика — показ, який він видає за відсутності впливу. Компенсується калібруванням. |
| bind | прив'язка | Одноразове спарювання receiver з конкретним RC transmitter, після якого receiver приймає команди лише від нього. Виконується за інструкцією до апаратури. |
| bootloader | завантажувач | Невелика програма у flash autopilot, яка запускається першою і дозволяє записати нову firmware через USB без спеціальних інструментів. |
| companion computer | допоміжний бортовий комп'ютер | Окремий комп'ютер на апараті (Raspberry Pi, Jetson тощо), який спілкується з autopilot через MAVLink — наприклад, для комп'ютерного зору. |
| compass | компас | Магнітометр, за яким autopilot визначає курс (yaw) відносно магнітної півночі. Часто розміщений в одному модулі з GPS. |
| deadzone | мертва зона | Діапазон сигналу, в якому ESC ще не обертає мотор. Від неї залежать `MOT_SPIN_ARM` і `MOT_SPIN_MIN`. |
| declination | магнітне схилення | Кут між магнітною і географічною північчю в даній місцевості. ArduPilot враховує його автоматично за вбудованою моделлю магнітного поля Землі. |
| DFU | режим прошивання через USB | Device Firmware Upgrade — вбудований у мікроконтролер STM32 режим, у якому можна записати bootloader і firmware, навіть якщо bootloader ArduPilot ще немає. |
| disarm | виведення з робочого стану | Дія, протилежна arm: мотори зупиняються і не реагують на газ. |
| disarmed | не в робочому стані | Стан після disarm або після ввімкнення живлення. Безпечний для налаштування і калібрувань. |
| EKF | розширений фільтр Калмана | Extended Kalman Filter — алгоритм, що поєднує дані IMU, GPS, compass, barometer тощо в єдину оцінку положення, швидкості й позиції апарата. У ArduPilot зазвичай працює EKF3. |
| ESC | електронний регулятор обертів | Electronic Speed Controller — перетворює сигнал autopilot на струм для безколекторного мотора. Один ESC на мотор (або 4-в-1). |
| failsafe | аварійний захист | Автоматична реакція autopilot на небезпечну ситуацію — втрату зв'язку, низький заряд батареї тощо: наприклад, посадка або RTL. |
| FFT | швидке перетворення Фур'є | Fast Fourier Transform — метод, що розкладає сигнал (наприклад, дані gyro) на частоти; так знаходять частоти вібрацій, які треба відфільтрувати. |
| firmware | прошивка | Програма ArduPilot, записана в autopilot. Для кожного типу апарата (Copter, Plane, Rover…) — окрема firmware. |
| flash | флеш-пам'ять | Енергонезалежна пам'ять мікроконтролера, де зберігаються bootloader і firmware. На платах з 1 MB flash частина функцій ArduPilot вимкнена. |
| flight controller | польотний контролер | Те саме, що autopilot. |
| flight mode | польотний режим | Спосіб, яким autopilot керує апаратом: від ручного стабілізування (Stabilize) до автономного польоту (Auto). Назви режимів не перекладаємо. |
| FPV | вигляд від першої особи | First Person View — пілотування за відео з камери на апараті, яке передається в окуляри чи на монітор пілота. |
| frame | рама | Конструкція апарата і схема розташування моторів (Quad X, Hexa, Y6…); задається параметрами `FRAME_CLASS` і `FRAME_TYPE`. |
| GCS | наземна станція керування | Ground Control Station — програма на комп'ютері чи телефоні (Mission Planner, QGroundControl) для налаштування апарата і контролю польоту. |
| GPIO | вивід загального призначення | General Purpose Input/Output — контакт, який firmware може використовувати як цифровий вхід чи вихід (реле, парашут, захоплювач), а не лише для PWM. |
| GPS lock | фіксація позиції GPS | Стан, коли GPS-приймач бачить достатньо супутників і визначає позицію; «3D GPS lock» — позицію разом із висотою. |
| gyro | гіроскоп | Датчик кутової швидкості. Разом з accelerometer входить до IMU. |
| IMU | інерційний вимірювальний модуль | Inertial Measurement Unit — блок з accelerometer і гіроскопа; основа, за якою autopilot визначає положення апарата в просторі. |
| level | рівне положення | Положення, яке autopilot вважає горизонтальним у польоті. Задається під час калібрування accelerometer. |
| log | журнал польоту | Файл із записом даних датчиків, команд і подій польоту; головний інструмент діагностики. У тексті: log-и, у log-ах. |
| notch | режекторний фільтр | Фільтр, що вирізає вузьку смугу частот (наприклад, шум від обертання моторів) і майже не зачіпає решту сигналу gyro. «Harmonic notch» — набір таких фільтрів на основній частоті й її гармоніках. |
| OSD | накладення даних на відео | On-Screen Display — виведення telemetry (висота, заряд батареї, режим тощо) поверх FPV-відео. Буває вбудованим в autopilot, зовнішнім (MinimOSD) або через MSP у цифрових системах. |
| PDB | плата розподілу живлення | Power Distribution Board — плата, що розводить струм батареї на всі ESC; часто має вбудований BEC і датчик струму. |
| PID | пропорційно-інтегрально-диференціальний регулятор | Регулятор, що обчислює корекцію з поточної похибки (P), накопиченої похибки (I) і швидкості її зміни (D). Коефіцієнти P, I, D підбирають під час tuning. |
| pit mode | режим мінімальної потужності | Режим VTX, у якому він передає з мінімальною потужністю (або майже не випромінює), щоб не заважати іншим пілотам, поки апарат на землі. |
| pitch | тангаж | Нахил носа апарата вгору-вниз — обертання навколо поперечної осі. |
| power module | модуль живлення | Модуль між батареєю і autopilot: подає на autopilot стабільне живлення і вимірює напругу та струм батареї. |
| pre-arm | передпольотна перевірка | Автоматичні перевірки перед arm. Якщо щось не налаштовано чи не відкалібровано, arm заборонено, а GCS показує повідомлення «PreArm: …». |
| PWM | широтно-імпульсна модуляція | Спосіб передачі команди тривалістю імпульсу, зазвичай 1000–2000 мкс. Так передаються канали RC і класичний сигнал на ESC і servo. |
| RC transmitter | пульт радіокерування | Пульт у руках пілота. Разом із receiver утворює канал ручного радіокерування. |
| receiver | приймач | Радіоприймач на апараті, що отримує команди з RC transmitter і передає їх autopilot. |
| roll | крен | Нахил апарата вліво-вправо — обертання навколо поздовжньої осі. |
| servo | сервопривід | Виконавчий механізм, що повертається на кут, заданий сигналом PWM (рулі, шасі, підвіс камери). |
| stick | ручка керування | Ручка на RC transmitter, що керує двома осями (наприклад, throttle і yaw). Розташування осей залежить від Mode 1/Mode 2. |
| telemetry | телеметрія | Двосторонній канал зв'язку між апаратом і GCS: дані польоту — на землю, команди — на апарат. Зазвичай окремий радіомодем. |
| throttle | газ | Команда тяги моторів: канал, ручка на RC transmitter або вихідне значення на мотори. |
| trim | підстроювання нейтралі | Значення каналу в нейтральному положенні ручки (параметри `RCx_TRIM`, `SERVOx_TRIM`), а також «тримери» на RC transmitter, що зсувають цю нейтраль. |
| tuning | точне налаштування | Підбір коефіцієнтів регуляторів (PID тощо) під конкретний апарат — вручну або через AutoTune. |
| UART | послідовний порт | Апаратний послідовний порт autopilot (TX/RX). У ArduPilot кожному UART відповідає логічний порт SERIALx з параметрами `SERIALx_PROTOCOL`, `SERIALx_BAUD`. |
| VTX | відеопередавач | Video Transmitter — передавач на апараті, що надсилає відео з камери на землю (аналоговий 5.8 ГГц або цифровий: DJI, Walksnail, HDZero). |
| yaw | рискання | Поворот апарата навколо вертикальної осі, тобто зміна курсу. |
