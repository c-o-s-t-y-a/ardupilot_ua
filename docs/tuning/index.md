# Tuning (точне налаштування)

> Оригінал: [Tuning](https://ardupilot.org/copter/docs/common-tuning.html)

Зі стандартними налаштуваннями PID (пропорційно-інтегрально-диференціальний регулятор) ArduPilot безпечно літає на більшості RC-апаратів одразу «з коробки». Щоб літати добре — з точною навігацією і надійною роботою на вітрі, — треба виконати tuning (точне налаштування) параметрів autopilot (автопілот). Як це зробити, описано в темах нижче.

2. [Підготовка до tuning](setup.md)
3. [Перший політ для tuning](initial-flight.md)
4. [Оцінювання tuning](evaluating.md)
5. [Ручний tuning](manual-roll-pitch.md)
6. [QuikTune](quiktune.md)
7. [AutoTune](autotune.md)
8. [Input Shaping](input-shaping.md)
9. [**Throttle Boost**](throttle-boost.md)
10. [Tuning з RC transmitter (пульт радіокерування)](transmitter-tuning.md)
11. [Налаштування notch (режекторний фільтр)](notch-filtering.md)
12. [FFT (швидке перетворення Фур'є) у польоті](fft.md)
13. [Боротьба з ground resonance](ground-resonance.md)
