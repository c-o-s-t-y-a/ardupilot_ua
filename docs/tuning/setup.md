# Підготовка апарата до tuning

> Оригінал: [Setting the Aircraft Up for Tuning](https://ardupilot.org/copter/docs/setting-up-for-tuning.html)

Наведені нижче параметри треба правильно задати відповідно до характеристик апарата. Кожен із них впливає на якість процесу tuning (точне налаштування).

### Налаштування батареї

Дуже важливо, щоб крива тяги моторів VTOL була якомога лінійнішою. Лінійна крива тяги означає, що зміна фактичної тяги мотора прямо пропорційна тязі, яку запитує ArduPilot. Якщо крива тяги сильно нелінійна, добрий tuning ви не отримаєте ніколи, а в деяких випадках tuning може вийти настільки поганим, що апарат стане повністю нестабільним і розіб'ється.

Є 3 поширені причини нелінійної кривої тяги:

- просідання напруги зі збільшенням throttle (газ);
- неправильно задані крайні точки діапазону PWM (широтно-імпульсна модуляція), який ви подаєте на ESC (електронний регулятор обертів) (див. «Налаштування моторів» нижче);
- нелінійність тяги, яку дає поєднання пропелера, ESC і мотора.

Почніть із налаштування діапазону напруги, щоб компенсувати просідання. Параметри для лінеаризації кривої тяги моторів:

- `MOT_BAT_VOLT_MAX` — максимальна напруга батарей, наприклад 4,2 В × кількість банок для звичайних LiPo або відповідне значення для іншого типу батарей.
- `MOT_BAT_VOLT_MIN` — мінімальна напруга батарей, наприклад 3,3 В × кількість банок для звичайних LiPo або відповідне значення для іншого типу батарей.
- `MOT_OPTIONS` = 0 (типово). Типово для наведених вище параметрів і під час обчислень tuning використовується напруга з компенсацією просідання. Значення 1 вмикає використання «сирої» напруги замість компенсованої, що може покращити результати tuning для легких апаратів.

Далі налаштуйте експоненту тяги. Якщо ви налаштовуєте професійний апарат, варто придбати стенд для вимірювання тяги, щоб точно виміряти справжню тягу вашого поєднання мотора/ESC/пропелера за різного throttle. Потім підберіть значення експоненти разом із крайніми точками (задаються в налаштуванні моторів нижче) так, щоб тяга між крайніми точками була якомога лінійнішою. Не довіряйте даним виробника щодо кривої тяги — вони часто неточні. Подробиці про масштабування тяги див. на сторінці [Motor Thrust Scaling](https://ardupilot.org/copter/docs/motor-thrust-scaling.html) *(ще не перекладено)*.

Якщо ви налаштовуєте апарат аматорського класу, правильне значення `MOT_THST_EXPO` для нього можна оцінити за графіком нижче.

- `MOT_THST_EXPO`: 0,55 для 5-дюймових пропелерів, 0,65 для 10-дюймових, 0,75 для 20-дюймових (або більших). Для найкращого результату цей параметр слід визначати за вимірюваннями на стенді (не довіряйте даним виробника).

![tuning-process-instructions-1.hires](https://ardupilot.org/copter/_images/tuning-process-instructions-1.hires.png)

> **Попередження.** Не задавайте експоненту вище 0,75, якщо у вас немає даних стенда для вашого поєднання мотора, ESC і пропелера, які показують, що потрібне більше значення. Графік — наближення для обладнання аматорського класу, і вгадане високе значення експоненти може зробити tuning апарата складнішим, а не легшим.

### Налаштування моторів

Параметри моторів задають діапазон виходу PWM, що подається на ESC. Це критично важливо, щоб увесь діапазон throttle, який використовується в польоті, лежав у лінійній ділянці вашої силової установки.

Параметри, що задають діапазон виходу на ESC:

- `MOT_PWM_MAX`: див. посібник ESC щодо фіксованого діапазону, або 2000 мкс.
- `MOT_PWM_MIN`: див. посібник ESC щодо фіксованого діапазону, або 1000 мкс.
- `MOT_SPIN_ARM`: за допомогою [перевірки моторів](../first-time-setup/connect-escs-and-motors.md#перевірка-напрямку-обертання-моторів) визначте значення, за якого мотори надійно починають обертатися на низьких обертах — як ознака стану armed (у робочому стані).
- `MOT_SPIN_MAX`: 0,95.
- `MOT_SPIN_MIN`: за допомогою [перевірки моторів](../first-time-setup/connect-escs-and-motors.md#перевірка-напрямку-обертання-моторів) і, якщо є, даних стенда задайте нижню межу лінійної тяги. Для аматорського використання зазвичай достатньо типового значення.
- `MOT_THST_HOVER`: 0,25 або нижче очікуваного фактичного відсотка тяги для висіння (нижче — безпечніше).

### Початкове налаштування PID-регулятора

Наведені нижче налаштування мають привести параметри прискорень і фільтрів PID (пропорційно-інтегрально-диференціальний регулятор) приблизно у правильний діапазон для вашого апарата. Ці параметри критично важливі для процесу tuning. Типові значення P/D/I для осей зазвичай безпечні для перших тестових висінь більшості апаратів.

- `INS_ACCEL_FILTER`: 10 Гц
- `INS_GYRO_FILTER`: 80 Гц для 5-дюймових пропелерів, 40 Гц для 10-дюймових, 20 Гц для 20-дюймових (або більших)
- `ATC_ACC_P_MAX`: 1100 для 10-дюймових пропелерів, 500 для 20-дюймових, 200 для 30-дюймових
- `ATC_ACC_R_MAX`: 1100 для 10-дюймових пропелерів, 500 для 20-дюймових, 200 для 30-дюймових
- `ATC_ACC_Y_MAX`: 200 для 10-дюймових пропелерів, 100 для 20-дюймових, 90 для 30-дюймових
- `ATC_RAT_PIT_FLTD`: `INS_GYRO_FILTER` / 2
- `ATC_RAT_PIT_FLTT`: `INS_GYRO_FILTER` / 2
- `ATC_RAT_RLL_FLTD`: `INS_GYRO_FILTER` / 2
- `ATC_RAT_RLL_FLTT`: `INS_GYRO_FILTER` / 2
- `ATC_RAT_YAW_FLTE`: 2
- `ATC_RAT_YAW_FLTT`: `INS_GYRO_FILTER` / 2
