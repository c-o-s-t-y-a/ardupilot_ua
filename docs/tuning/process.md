# Інструкції з процесу tuning

> Оригінал: [Tuning Process Instructions](https://ardupilot.org/copter/docs/tuning-process-instructions.html)

Процес tuning (точне налаштування) складається з таких кроків:

1. [Налаштування параметрів для підготовки до перших польотів tuning](setup.md).
2. [Перший політ для tuning](initial-flight.md), щоб отримати стабільний, хоч і не обов'язково оптимальний, tuning.
3. [Оцінювання початкового стабільного tuning](evaluating.md).
4. Налаштування notch (режекторний фільтр) проти шуму, див. [Налаштування notch-фільтрів](notch-filtering.md).
5. [Ручний tuning roll (крен) і pitch (тангаж)](manual-roll-pitch.md) і/або скрипт [QuikTune](quiktune.md) (обов'язково перед спробою використати AUTOTUNE!).
6. [AUTOTUNE](autotune.md).
7. Налаштування параметрів [Input Shaping](input-shaping.md), щоб отримати бажане «відчуття» керування.

Початковий tuning апарата слід виконувати **в його найманевренішій конфігурації**. Зазвичай це означає мінімальну злітну масу з повністю зарядженими батареями.

> **Примітка.** Якщо виконати кожен із наведених кроків, процес tuning зазвичай буде безпечним, а результат — достатнім для більшості користувачів. Як альтернативу для покрокового налаштування можна використати [Methodic Configurator](https://ardupilot.github.io/MethodicConfigurator/).

## Розширений tuning

ArduCopter має надзвичайно гнучку архітектуру регуляторів, яку з чудовими результатами використовують на апаратах від 100 г до 500 кг. Є низка складних задач керування, що потребують глибшого розуміння, ніж можна дати тут. Серед них:

- високий рівень шуму gyro (гіроскоп);
- гнучкі конструкції frame (рама);
- м'які віброгасники;
- великі корисні навантаження на гнучких чи нежорстких кріпленнях;
- виконавчі механізми з обмеженою швидкістю;
- нелінійні виконавчі механізми;
- надзвичайно агресивний або динамічний політ.
