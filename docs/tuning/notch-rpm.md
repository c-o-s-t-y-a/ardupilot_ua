# Налаштування динамічного notch за датчиком обертів

> Оригінал: [RPM Sensor Based Dynamic Notch Setup](https://ardupilot.org/copter/docs/common-rpm-based-notch.html)

- Налаштуйте [датчик обертів](https://ardupilot.org/copter/docs/common-rpm.html) *(ще не перекладено)*.
- Встановіть `INS_HNTCH_MODE` і/або `INS_HNTC2_MODE` = 2 або 5, щоб частоту гармонічного notch (режекторний фільтр) задавав датчик обертів.
- Встановіть `INS_HNTCH_ENABLE` і/або `INS_HNTC2_ENABLE` = 1, щоб увімкнути гармонічний notch.
- Встановіть `INS_HNTCH_REF` і/або `INS_HNTC2_REF` = 1, щоб опорне значення гармонічного notch було без масштабування, — хіба що датчик обертів показує лише частку справжніх обертів гвинта. Таке можливо в трансмісії з редуктором. Якщо, наприклад, датчик показує 1/3 справжніх обертів, задайте 0,33.
- Встановіть `INS_HNTCH_FREQ` і/або `INS_HNTC2_FREQ` нижче частоти висіння. У динамічному notch за обертами цей параметр задає нижню межу частоти notch. Тобто навіть якщо датчик обертів покаже менше значення, центральна частота notch не опуститься нижче значення цього параметра. Частоту висіння легко визначити, повисівши й переглянувши дані датчика обертів у log (журнал польоту) (наприклад, RPM.rpm1).
- Встановіть `INS_HNTCH_BW` і/або `INS_HNTC2_BW` = половина `INS_HNTCH_FREQ`.

## Перевірка ефективності гармонічного notch

Після налаштування перевірте роботу фільтра(ів), виконавши ще один тестовий політ після налаштування фільтрів, як описано на сторінках [**IMU Batch Sampler**](batch-sampling.md) або [**Raw IMU Logging**](raw-imu-logging.md), і проаналізуйте log.

Хоча для режиму за обертами аналіз частот шуму в log перед налаштуванням notch не є обов'язковим, за бажання можна виконати запис і аналіз для контрольного польоту цим методом, щоб підтвердити усунення шуму.
